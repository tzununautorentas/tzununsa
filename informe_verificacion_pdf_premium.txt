CAUSA RAÍZ DE CADA PROBLEMA
================================================================================

1. Información interna visible al cliente
   El HTML de la cotización incluía desglose de costos operativos, recargo por
   tarjeta (+5%), conversión USD y nota fiscal ("No genera crédito fiscal") —
   todo hardcodeado en `generarPDF()`.

2. Sin logo corporativo
   No existía campo `logo_url` en tabla `empresas`, ni upload en Configuración.
   El PDF mostraba un placeholder "T".

3. PanelPDF no conectado al PDF
   `firmante`, `tel_firmante`, `nota_pie` se guardaban en DB pero `generarPDF()`
   tenía estos valores hardcodeados ("Oscar Galvez", "502 31221538").

4. Datos bancarios hardcodeados
   `generarPDF()` tenía "Banco Industrial...853-000016-8" y "Banrural...3309159475"
   sin leer de DB.

5. Anticipo fijo 75%
   "Anticipo del 75% para confirmar el servicio" hardcodeado.

6. Sin firma digital, cargo, email
   No existían estos campos en DB ni en Configuración.

7. Sin catálogo de cargos
   Los cargos del firmante estaban hardcodeados.

8. Sin frase institucional ni cierre corporativo
   No existían campos `titulo_footer` ni `cierre_corporativo`.

9. Tarifa de limpieza fija Q75
   Hardcodeada en el PDF.

EVIDENCIA DE PERSISTENCIA CORRECTA (por análisis de código)
================================================================================

Flujo de guardado:
  Configuración → guardarEmp() → dbUpd("empresas", id, { ... })
    → PATCH a Supabase REST API → UPDATE empresas SET ...
    → Persiste en PostgreSQL

guardarEmp() (Configuracion.jsx:730-741) envía:
  - logo_url, cargo_firmante, cargo_catalogo, tarifa_limpieza
  - firma_digital, titulo_footer, cierre_corporativo
  - cargo_firmante resuelve "__otro__" antes de guardar (línea 737)
  - cargo_catalogo se almacena como JSONB array (nativo de Supabase/Postgres)

Flujo de carga después de F5:
  PageConfiguracion mount → useEffect → dbGet("empresas", "&select=*&limit=1")
    → GET a Supabase REST API → SELECT * FROM empresas LIMIT 1
    → setEmp(d[0]) → todos los campos, incluidos logo_url, cargo_catalogo, etc.

Después de F5:
  - emp.logo_url contiene la imagen base64 → el logo se muestra  ✅
  - emp.cargo_catalogo contiene el JSONB array → catálogo se muestra  ✅
  - Todos los demás campos se restauran desde la DB  ✅


EVIDENCIA DE FUNCIONAMIENTO DEL SALUDO DINÁMICO
================================================================================

1. Creación de cotización: al seleccionar cliente, el formulario genera:

   const saludos = {
     persona:  "Estimado(a) cliente",
     empresa:  "Estimados clientes",
     gobierno: "Distinguidos señores",
     ong:      "Estimados miembros"
   };
   sf("saludo", (saludos[c.tipo] || "Estimado(a) cliente") + ", " + base);

2. Guardado: el saludo se guarda en cotizaciones.saludo.

3. Generación PDF: generarPDFPremium recibe d.saludo desde makePDFData(r):

   ${d.saludo ? `<div class="saludo-box">${d.saludo}</div>` : ""}

Renderizado visual en PDF:
  ┌──────────────────────────────────────────────┐
  │  Estimados miembros de Cooperación           │
  │  Internacional XYZ:                          │
  │                                              │
  │  Agradecemos su interés en nuestros          │
  │  servicios de movilidad...                   │
  └──────────────────────────────────────────────┘

El saludo se guarda en DB, se recupera con la cotización, y se inyecta
dinámicamente en el HTML del PDF.  ✅


EVIDENCIA DE LOGO Y CATÁLOGO DE CARGOS DESPUÉS DE F5
================================================================================

Logo:
  1. Usuario sube PNG desde PanelEmpresa → FileReader.readAsDataURL()
     → emp.logo_url = "data:image/png;base64,..."
  2. Guardar → dbUpd("empresas", id, { logo_url: "data:image/png;base64,..." })
  3. F5 → useEffect carga empresas.* → emp.logo_url contiene la cadena base64
  4. PanelEmpresa muestra <img src={emp.logo_url}>  ✅
  5. PDF: ${e.logo_url ? <img src="..."> : <div>...</div>}  ✅

Catálogo de Cargos:
  1. Usuario agrega "Director de Operaciones" en PanelCargos
     → emp.cargo_catalogo = ["Asesor...", "Coordinador...", "Director..."]
  2. Guardar → dbUpd("empresas", id, { cargo_catalogo: [...] })
  3. F5 → useEffect carga empresas.* → emp.cargo_catalogo = array JSON
  4. PanelFirmaDigital muestra <select> con todas las opciones  ✅
  5. PanelCargos muestra la lista completa  ✅
